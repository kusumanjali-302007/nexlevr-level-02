# Number Vault: Smart Contract Frontend (SimpleStorage dApp)

A beginner-friendly Ethereum project. A web page lets you **store a number** on the blockchain and **retrieve it**, using MetaMask to sign transactions.

**Stack:** Solidity 0.8.20 · Hardhat · Ethers.js v6 · MetaMask · HTML/CSS/JavaScript · Vercel or GitHub Pages

## Project structure

```
smart-contract-frontend/
├── contracts/SimpleStorage.sol     Smart contract (store + retrieve)
├── scripts/deploy.js               Deploys the contract and writes public/contract-config.js
├── test/SimpleStorage.test.js      Unit tests (Hardhat + Chai)
├── public/
│   ├── index.html                  Page layout
│   ├── style.css                   Responsive styling (light/dark)
│   ├── app.js                      Wallet + contract logic (Ethers.js)
│   └── contract-config.js          Contract address + ABI (generated by deploy script)
├── hardhat.config.js               Hardhat settings (localhost + optional Sepolia)
├── package.json                    Dependencies and npm scripts
├── vercel.json                     Tells Vercel to serve the public/ folder
├── .env.example                    Template for secrets (copy to .env)
└── .gitignore
```

## 1. Install tools

1. Install [Node.js](https://nodejs.org/) 18 or newer (LTS recommended). Check with `node -v`.
2. Install [Git](https://git-scm.com/) and the [MetaMask](https://metamask.io/download/) browser extension (create a wallet if you don't have one).
3. In this folder run:

```bash
npm install
```

## 2. Compile and test

```bash
npx hardhat compile
npm test
```

The tests cover: initial value is 0, storing and retrieving, overwriting, the maximum `uint256`, storing from a different account, and the `NumberStored` event.

## 3. Start a local blockchain and deploy

Open **two terminals** in the project folder.

**Terminal 1** (leave running):
```bash
npm run node
```
It prints 20 test accounts, each with 10000 test ETH and a private key.

**Terminal 2:**
```bash
npm run deploy:local
```
You will see `SimpleStorage deployed to: 0x...`. The script also writes that address and the ABI into `public/contract-config.js`, so the frontend is configured automatically.

**Getting the address and ABI manually:** the address is printed by the deploy script. The ABI is in `artifacts/contracts/SimpleStorage.sol/SimpleStorage.json` under the `abi` key (created after compiling).

> Restarting `npm run node` resets the chain. Re-run `npm run deploy:local` afterwards.

## 4. Configure MetaMask for local development

1. MetaMask → network menu → **Add a custom network**.
2. Enter: Network name `Hardhat Local`, RPC URL `http://127.0.0.1:8545`, Chain ID `31337`, Currency symbol `ETH`.
3. Import a funded test account: MetaMask → **Import account** → paste one private key printed by `npm run node` (account #0 is fine).
4. **Use these test keys only on your local chain, never on real networks.**

The website can also offer to add/switch this network for you via the *Switch MetaMask network* button.

If MetaMask shows nonce errors after you restart the node: Settings → Advanced → **Clear activity tab data**.

## 5. Run the frontend locally

```bash
npm run frontend
```
Open http://localhost:3000, click **Connect wallet**, approve in MetaMask, type a number, click **Store number**, confirm in MetaMask, then click **Retrieve number**.

Do not open `index.html` by double-clicking it (a `file://` page may not work with MetaMask); use the command above.

## 6. Push to GitHub

```bash
git init
git add .
git commit -m "Initial commit: SimpleStorage dApp"
git branch -M main
```
Create an empty repository on github.com (no README/license), then:
```bash
git remote add origin https://github.com/<your-username>/smart-contract-frontend.git

```
`.env`, `node_modules/` and build output are ignored by `.gitignore`. **Never commit a real private key.**

## 7. Make it work for other people (public testnet, required)

A local blockchain exists only on your computer. If you deploy the website while `public/contract-config.js` points to a local address, visitors will see a wrong-network or "no contract found" message. To make a public site work, deploy the contract to **Sepolia** first:

1. Create a **new throwaway MetaMask account** just for testing and export its private key (Account details → Show private key).
2. Get free Sepolia test ETH from a faucet (search "Sepolia faucet"; examples include the Google Cloud Web3 faucet and Alchemy's faucet).
3. Get a Sepolia RPC URL from [Alchemy](https://www.alchemy.com/), [Infura](https://www.infura.io/) or a similar provider.
4. Copy `.env.example` to `.env` and fill in `SEPOLIA_RPC_URL` and `PRIVATE_KEY`.
5. Deploy:
   ```bash
   npm run deploy:sepolia
   ```
   This rewrites `public/contract-config.js` with the Sepolia address and chain id `11155111`.
6. Commit and push the updated `public/contract-config.js` (it contains only a public address and ABI, no secrets):
   ```bash
   git add public/contract-config.js
   git commit -m "Point frontend to Sepolia deployment"
   git push
   ```
7. Optionally verify on `https://sepolia.etherscan.io/address/<your-address>`.

Visitors need MetaMask set to Sepolia (the site's *Switch MetaMask network* button helps) and a little Sepolia ETH for the store transaction. Reading works without paying gas.

## 8. Deploy the frontend

### Option A: Vercel
1. Sign in at [vercel.com](https://vercel.com) with GitHub → **Add New → Project** → import your repository.
2. Leave the build command empty. `vercel.json` already sets the output directory to `public`. Click **Deploy**.
3. Your live URL looks like `https://smart-contract-frontend-xxxx.vercel.app`. That is the link to share.

### Option B: GitHub Pages
GitHub Pages serves a branch folder only from the root or `/docs`, so rename the folder:
```bash
git mv public docs
git commit -m "Serve site from docs/"
git push
```
Then repo → **Settings → Pages** → Source: *Deploy from a branch* → Branch `main`, folder `/docs` → Save. The URL will be `https://<your-username>.github.io/smart-contract-frontend/`.
(If you do this, `scripts/deploy.js` writes to `public/`. Change the `"public"` path in it to `"docs"` before redeploying the contract.)

## How the frontend talks to the smart contract (simple explanation)

- **MetaMask** is a wallet that injects an object called `window.ethereum` into the page. It holds your keys; the website never sees them.
- **Ethers.js** wraps that object. `BrowserProvider` lets the page *read* the blockchain, and a **signer** (your account) lets it *send transactions*.
- A **contract object** is created from the contract's **address** (where it lives) and **ABI** (a list of its functions and their types). That is why `contract-config.js` exists: it hands both to the page.
- **Retrieve** calls `retrieve()`, a `view` function. It only reads, so it's free and needs no confirmation.
- **Store** calls `store(number)`, which changes data. MetaMask asks you to confirm and pay gas, the transaction is sent (you get a hash), then the page waits for it to be mined (`tx.wait()`) before saying "Stored".

## Error handling in the frontend

| Situation | What the user sees |
|---|---|
| No MetaMask installed | Warning with install link |
| Not connected | Instructions box; Store/Retrieve buttons disabled |
| Wrong network | Red network status, "Switch MetaMask network" button, actions disabled |
| Contract address not configured / no contract at address | Clear message to deploy or redeploy |
| Rejected in MetaMask | "You rejected the request… Nothing was sent." |
| Invalid input (empty, negative, decimal, too large) | Message before any transaction is made |
| Pending transaction | Spinner plus transaction hash |

## Troubleshooting

- **"Wrong network"**: switch MetaMask to the network named on the page (Hardhat Local = chain 31337, Sepolia = 11155111).
- **"No contract found at 0x…"**: you restarted the local node or MetaMask is on another network. Re-run `npm run deploy:local` and reload the page.
- **Transaction stuck / nonce errors on local chain**: MetaMask → Settings → Advanced → Clear activity tab data.
- **`HH502` / compiler download error**: Hardhat needs internet access to download the Solidity compiler on first compile.
- **Sepolia deploy fails with insufficient funds**: fund the deployer account from a faucet.
- **Page shows old contract after redeploy**: hard refresh (Ctrl/Cmd+Shift+R).
- **Port 3000 busy**: edit the port in the `frontend` script in `package.json`.

## Security notes

This is a learning project. The contract has no access control (anyone can overwrite the number), which is intentional for simplicity. Keep private keys out of Git, and use throwaway accounts for testnets.
