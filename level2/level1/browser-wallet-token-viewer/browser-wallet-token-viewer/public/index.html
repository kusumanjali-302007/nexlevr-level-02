How to connect MetaMask to the local Hardhat network
  1. Open MetaMask, click the network picker, then choose Add a custom network.
  2. Network name: Hardhat Local
  3. RPC URL: http://127.0.0.1:8545
  4. Chain ID: 31337   Currency symbol: ETH
  5. Save, then switch to the new network. You can also use the switch buttons that appear when you are on the wrong network.
